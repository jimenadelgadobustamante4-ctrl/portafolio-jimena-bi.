# Jimena Delgado Bustamante

## Portafolio de Business Intelligence y análisis de datos

Estudiante de Ingeniería en Desarrollo de Software en la Universidad Fidélitas, Costa Rica. Este portafolio reúne proyectos académicos y de práctica con **Power BI, Power Query, DAX, SQL Server y Microsoft Excel**, orientados al análisis de datos y a la interpretación de necesidades del negocio.

## Conocimientos representados

- Análisis de ventas e indicadores de cumplimiento de metas.
- Preparación de datos con Power Query y lenguaje M.
- Medidas DAX y diseño de un modelo de datos para BI.
- Bases de datos relacionales, claves, restricciones y consultas SQL.
- Visualización de datos y elaboración de dashboards en Excel.
- Documentación de proyectos, preguntas de negocio y definición de métricas.

## Alcance de los proyectos

Los casos contienen datos académicos o simulados. **NEXORA incluye datos, consultas, medidas DAX y documentación para implementar la solución; no incluye un reporte `.pbix` terminado.**

Los proyectos Lovable se presentan mediante sus enlaces externos. Su código fuente no está incluido en este repositorio y los enlaces del editor pueden requerir permisos de acceso.
